# 모던 포켓몬 매니저 (Modern Pokémon Manager)

> 포켓몬이 몬스터볼을 떠나 사람처럼 살아가는 시대. 당신은 포켓몬 프로 리그 클럽의 감독이다.

**Football Manager 스타일 클럽 경영 + 자동 6 대 6 포켓몬 배틀** 무료 팬게임입니다.
감독은 전투 중에 명령하지 않습니다. 영입하고, 계약하고, 키우고, 엔트리를 짜고 — 그다음은 포켓몬이 스스로 싸웁니다.

## 다운로드

👉 **[Releases](../../releases)** 에서 최신 버전을 받으세요.

| 파일 | 설명 |
| --- | --- |
| `ModernPokemonManager-<버전>-portable.exe` | **추천.** 받아서 더블클릭하면 바로 실행. 설치 필요 없음. 첫 화면까지 최대 20초 정도 걸릴 수 있어요. |
| `ModernPokemonManager-<버전>-setup.exe` | 설치형. 시작 메뉴·바탕화면 바로가기가 생기고 실행이 빠릅니다. |

둘 중 **하나만** 받으면 됩니다. 인터넷 연결이나 다른 프로그램은 필요 없어요. 그림·소리·음악이 전부 파일 안에 들어 있습니다.

### 처음 실행할 때

- **"Windows의 PC 보호"** 창이 뜨면 → **추가 정보 → 실행**을 누르세요. 개인이 만든 프로그램이라 뜨는 경고입니다.
- 처음 실행하면 **언어(English / 한국어)** 를 고른 뒤 프롤로그가 시작됩니다. 나중에 설정에서 바꿀 수 있어요.
- 조작은 **마우스만** 씁니다. F11은 전체 화면입니다.

### 요구 사양

- Windows 10 / 11 (64비트)
- 화면 1280×720 이상 (16:9, 21:9 와이드 모두 지원)
- 저장 공간 약 600MB

### 저장 파일

- 저장 위치: `%APPDATA%\ModernPokemonManager`
- 설치형과 포터블은 같은 저장을 씁니다.
- **v0.0.2부터 저장 형식이 바뀌어 v0.0.1 저장은 불러올 수 없습니다** — 새 게임을 시작해 주세요. 옛 저장은 불러오기 목록에 "이전 버전"으로 표시되고 지울 수 있습니다.

## 어떤 게임인가요

- **6부 리그에서 1부까지** — 6단계 리그 × 10클럽. 최하위권 클럽으로 시작해 매 시즌 승격을 노립니다.
- **대회** — 리그, 레드컵·오크컵(토너먼트), 케첨컵(챔피언 결정전), 4시즌마다 열리는 넥스트컵(세대 대표팀).
- **레벨 없는 세계** — 경기에 나가 싸우는 것이 곧 성장. 많이 뛸수록 진화하고 강해지지만, 최종 진화 뒤에는 은퇴가 다가옵니다.
- **같은 종도 다른 개체** — 개체마다 다른 종족값, 전투 지능 INT 0~3, 결정력 DET, 그리고 보이지 않는 숨은 성향.
- **자동 배틀** — 원작 턴제 규칙 그대로. 2.5D 관전 화면, 기술 이펙트, 배속·스킵·하이라이트.
- **클럽 운영** — 이적시장과 협상(합의 7일 뒤 합류, 그사이 다른 클럽의 경쟁 제안), 매일 움직이는 AI 이적시장과 이적 소식, 급여와 계약, 만족도와 클럽 충성, 스태프, 스카우터, 상점·경매장·알·스킬 드라이브, 주장.
- **전설의 역제의** — 처음 1부로 승격하면 소속 없는 전설·환상 포켓몬이 먼저 입단을 제안해 옵니다 (커리어에 한 번).
- **특수 진화** — 메가진화·원시회귀 등은 특별한 도구를 들고 경기에 들어갈 때만.
- **커리어 엔딩** — 1부 리그와 레드·오크·케첨컵을 모두 우승하면 은퇴하고 엔딩을 볼 수 있습니다.

화면마다 튜토리얼이 있고, 오른쪽 위 **?** 버튼으로 언제든 다시 볼 수 있어요.

## English

**Modern Pokémon Manager** is a free fan game: Football Manager-style club management plus fully automatic 6v6 Pokémon battles. Pokémon have left their Poké Balls and live like people — you are the manager of a pro league club. You don't give orders in battle: you sign, contract, develop and pick the line-up, and the Pokémon fight on their own.

### Download

Get the latest version from **[Releases](../../releases)** — you only need one file:

- `ModernPokemonManager-<version>-portable.exe` — **recommended**: double-click to play, no install (first launch can take up to ~20 s).
- `ModernPokemonManager-<version>-setup.exe` — installer with shortcuts, faster start.

No internet or other software needed — all art, sound and music are inside the file.

- If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**.
- On first launch you pick a language (English / 한국어) before the prologue; you can change it later in Settings.
- Mouse only; F11 toggles full screen.
- Windows 10/11 64-bit, 1280×720 or larger (16:9 and 21:9), ~600 MB of disk.
- Saves are kept in `%APPDATA%\ModernPokemonManager` (shared by both files). **Saves from v0.0.1 can't be loaded in v0.0.2 or later** — please start a new game.
